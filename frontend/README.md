# UniServe Frontend

React 18, Vite and Tailwind CSS client for UniServe.

## Run locally

    cd frontend
    npm install
    cp .env.example .env
    npm run dev      # http://localhost:5173
    npm test

## Settings

- VITE_API_URL: address of the backend API (default http://localhost:4000/api)
- VITE_UNIVERSITY_NAME: name shown in the header

## Deployment

Deployed on Vercel with Root Directory set to `frontend`.
